# Code of conduct

System One Bench follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good faith, criticise results and code rather than people, and keep discussions about
models factual. That includes discussions of your own model or a competitor's.

## Reporting

Report behaviour that breaks the code of conduct to the maintainer, [@alilibx](https://github.com/alilibx), through a
[private security advisory](https://github.com/alilibx/system-one-bench/security/advisories/new), which only the
maintainer can read. Reports are kept confidential. The maintainer decides on a response following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).

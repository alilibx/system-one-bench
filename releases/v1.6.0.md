A redesign of [systemonebench.dev](https://systemonebench.dev/) and a pass that checks every claim on the site and in the README against the results files (#12). No runs, data or scores changed.

## New on the site
- **Search** (press `/`) and maker filters, applied to every chart and table at once. The filter is kept in the URL, so a view like `?q=clef` or `?maker=Perplexity` can be shared.
- **One leaderboard for both tracks**: System One Index, English, Arabic and Vision Index side by side, sortable by any column. Click a model to see its run details and every dataset score with its rank.
- **A leader for each track.** The headline names Decider V1.1 27B as text leader (83.4, 0.7 ahead of d1) and Jev 1.14 as vision leader (85.1, 1.2 ahead of Jev 1.13), and says the text leader is 3rd on images. It's computed from the data, so it stays true as models are added.
- A header that stays on screen, section labels for each track, a light/dark switch, and a phone layout.

## Corrected
- The "fastest 5" latency card ranked Laya first with a time measured locally on a Mac, which doesn't compare with API round trips. Latency charts now compare API models only.
- README: 7 open-weight roadmap entries (not 6), Decider V1.1's median latency 263 ms, and Jev 1.14 described as the fastest *API* model.

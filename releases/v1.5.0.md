An image benchmark for every model on OpenRouter's Decisions API that reads images, the benchmark data frozen so later models run on exactly the same bytes, and written rules for every run (#11). Plus the project's **first outside contribution** (#9).

## Vision track
1,200 image cases across 6 datasets: the 200 SST-2 reviews and 200 Arabic tweets drawn as pictures (a like-for-like test of reading from pixels), Oxford-IIIT Pet, VQAv2 yes/no, CountBench, and RefCOCO for Box questions. The **Vision Index** is the mean accuracy over the first 5, kept apart from the System One Index.

| Model | Vision Index | Calibration error | Median latency | Cost per 1,000 calls |
|---|---|---|---|---|
| **Jev 1.14** | **85.1** | 2.9% | **183 ms** | $0.046 |
| Jev 1.13 | 83.9 | **2.8%** | 192 ms | $0.046 |
| Decider V1.1 27B | 83.0 | 5.6% | 302 ms | $0.009 |
| GPT-6 Luna Decisions | 81.6 | 5.3% | 221 ms | $0.047 |
| Mercury Decide | 79.4 | 9.9% | 305 ms | free tier |
| Clef | 78.1 | 3.6% | 502 ms | $0.138 |
| Clef Flash | 78.0 | 9.4% | 429 ms | $0.022 |
| Clef Omni | 72.2 | 20.6% | 274 ms | $0.086 |

- The two indexes rank models differently: Decider V1.1 27B leads text but is 3rd on images; Jev 1.14 leads images and is 8th on text.
- Reading English from a picture costs every model at most 7.5 points; reading Arabic costs 12.5 to 23.5.
- **Box questions** (Jev 1.14 only): 78.5% of boxes overlap the labelled one by at least half, at an average stated confidence of 48%.
- d1, Microsoft-Decision-1, Kev 4B, Tev1, Solar Decide, Solar Decide Flash and Drex reject images, so they have no vision score rather than a zero.

## Frozen data
- `data.lock.json` holds a SHA-256 for every dataset and image; `run_decisions.py` and `score.py` refuse data that doesn't match.
- Every source is pinned to a fixed commit, and `.github/workflows/data.yml` rebuilds everything from scratch on data PRs and every Monday.
- The text cases are the same 3,250 every earlier release used.

## Benchmark rules
`CONTRIBUTING.md` and a PR template checklist: frozen data, identical requests, failures count as wrong, latency from one machine, runs added without disturbing others, and only scores measured here on the site.

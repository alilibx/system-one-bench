Four decision models that appeared on OpenRouter's Decisions API, on all 3,250 cases with 8 calls in flight (#7), and a runner that reaches models outside OpenRouter (#8).

## Results
| Model | Maker | Index | Calibration error | Median latency | Cost per 1,000 calls |
|---|---|---|---|---|---|
| **Decider V1.1 27B** | Perplexity | **83.4** | 5.7% | 678 ms | **$0.009** |
| Clef Omni | Cloudflare | 79.7 | 3.4% | 544 ms | $0.074 |
| Drex v1.5 | Nace AI | 77.6 | 10.8% | 608 ms | $0.010 |
| Solar Decide Flash | Upstage | 63.6 | 14.4% | 908 ms | $0.042 |

- **Decider V1.1 27B leads the System One Index** and is the cheapest paid model. Perplexity retired Decider V1 (its slug returns 404), so V1.1 replaces it on the charts; the V1 run is kept for reference.
- Solar Decide Flash shares Solar Decide's 26-option limit and fails all 200 Banking77 cases.

## Also in this release
- `run_decisions.py --provider fastino|celeris|hanzo|meragpt` calls each vendor's own API with the same request body, and `--url` reaches any compatible endpoint, including a local `llama-server` (#8).
- README: a section on running open-weight models locally (llama.cpp GGUF builds, Hugging Face `system_one`, `kev.serve`).
- The roadmap is rebuilt and grouped by what each model needs; scatter labels get leader lines so every dot is labelled.

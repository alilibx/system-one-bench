The repository now reads like a mature open-source project. No runs, data or scores changed.

## What's new
- **Logo:** the System One Bench mark and wordmark head the README, in light and dark versions ([`docs/assets/`](https://github.com/alilibx/system-one-bench/tree/main/docs/assets)).
- **Live badges:** the site now publishes [shields.io endpoint](https://shields.io/badges/endpoint-badge) badges at `systemonebench.dev/badge/models.json`, `text-leader.json` and `vision-leader.json`, written from the results at every deploy. The README shows them with the latest release, the frozen-data check, licences and citation.
- **Quick start and contents:** the README opens with the six commands from clone to a scored run, and a list of every section.
- **Community files:** a [code of conduct](https://github.com/alilibx/system-one-bench/blob/main/CODE_OF_CONDUCT.md), a [security policy](https://github.com/alilibx/system-one-bench/blob/main/SECURITY.md), a [problem report form](https://github.com/alilibx/system-one-bench/issues/new?template=report-a-problem.yml) next to the model request, `CODEOWNERS` and `.editorconfig`.
- **Dependabot** keeps the workflows' actions current. The Python packages stay pinned, since they build the frozen data.

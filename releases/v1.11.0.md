Round 8 runs seven decision models that joined OpenRouter's Decisions API since round 4 on all 3,250 text cases, and the four that read images on the vision track. Both indexes have a new leader. The data, the other runs and their scores are unchanged.

## New on the board
| Model | Maker | System One Index | Rank | Vision Index | Rank |
|---|---|---|---|---|---|
| Decider V1.2 | Perplexity | **84.6** | 1st of 30 | 83.8 | 5th of 11 |
| Drex Max | Nace AI | 84.1 | 2nd | | |
| d1-ultra | Liquid AI | 82.9 | 3rd | 85.6 | 2nd |
| Decider Flash V1.2 | Perplexity | 81.9 | 7th | 77.5 | 10th |
| Span-02 | Respan | 79.5 | 11th | **86.1** | 1st |
| Drex v2.0 | Nace AI | 78.6 | 14th | | |
| Classify-1 | ScaleDown | 30.6 | 30th | | |

- **Decider V1.2 leads the System One Index**, 1.2 points above Decider V1.1, and is the best calibrated model on the board (0.7%). Drex Max is 0.5 points behind it, and d1-ultra is 3rd.
- **Span-02 leads the Vision Index**, 1.0 point above Jev 1.14, and loses far less than any other model reading Arabic from a picture. It's Respan's first model to take a normal state; Span-01 only takes a conversation.
- **Decider Flash V1.2 is the fastest API model on the board** (104 ms median) and, with Span-02, the cheapest ($0.005 per 1,000 calls).
- **Classify-1 rejects most of our cases**: it only accepts a state that is plain text, so it answered the 200 DAIR Emotion cases and failed the other 3,050, which count as wrong. It also rejects images, so it has no vision score.
- Drex Max, Drex v2.0 and Classify-1 don't read images. None of the new models answers Box questions.
- Latency was timed from a different cloud server than the board's 15 October timings. A control run of Jev 1.14 measured 122 ms there against 136 ms on the board, so the new latencies compare to within about 10%.

## Retired
**Decider V1.1 27B** has left OpenRouter's catalog and returns 404, so it's tagged retired and left out of the charts and rankings like Decider V1. Its run stays on the board for reference. Decider V1.2 replaces it in the live race, where the other new models (except Classify-1) join it too.

## Not run yet
Baseten's **Mammoth 1** (27B) and **Elephant 1** (9B) are on OpenRouter's free tier only, which allows 1,000 requests a day against the 3,341 a run takes. Mammoth 1's run is under way; both will go on the board once they finish under the same rules. Their MIT open weights are the fallback.

## Roadmap
Added: Baseten's Mammoth 1 and Elephant 1, THX-01 and vLLM's Decision-1.0 Eos 0.8B for the next CPU round; Cloudflare Clairic, which extracts typed values rather than making decisions, needs a track of its own; the unconfirmed Fastino GLiDE v1.2 and the Clinical System One (CS1) paper are on the watch list.

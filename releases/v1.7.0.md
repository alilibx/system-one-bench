System One Bench is now openly licensed and citable, and shares well. No runs, data or scores changed.

## What's new
- **Licence:** the code is [Apache-2.0](https://github.com/alilibx/system-one-bench/blob/main/LICENSE) and the results are CC BY 4.0, so anyone can reuse them with a link back. Cases and images keep their source datasets' licences.
- **Citation:** `CITATION.cff`, so GitHub offers "Cite this repository".
- **Link previews:** shared links to [systemonebench.dev](https://systemonebench.dev/) now show a title, description and card image on LinkedIn, X, Slack and Discord. The site also has a favicon, `robots.txt` and `sitemap.xml`.
- **Request a model:** a [new issue form](https://github.com/alilibx/system-one-bench/issues/new?template=request-a-model.yml) to ask for a run in public.
- **Badge:** model makers can link their model card to its results with a "Scored on System One Bench" badge (see the README).
- **Plan:** [docs/plan.md](https://github.com/alilibx/system-one-bench/blob/main/docs/plan.md) lists what's next: per-model pages, a technical report, open-weight runs, and a one-command way to score your own model.

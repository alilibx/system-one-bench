The project becomes **System One Bench**, with a public results site and its first API comparison: TypeSafe Jev 1.13 against OpenAI's GPT-6 Luna Decisions, both through OpenRouter's Decisions API.

## What's new
- `run_decisions.py`: a resumable runner for OpenRouter's Decisions API (`POST /api/alpha/decisions`). Every model gets byte-identical request bodies. `score.py` now records billed cost and tokens (#1).
- The results site in `site/`, laid out like Artificial Analysis: the **System One Index** (mean accuracy over the 16 datasets, equal weight per dataset, with English and Arabic sub-indexes), index-against-latency and index-against-cost scatters, calibration, latency and cost charts, and one chart per dataset. `.github/workflows/pages.yml` publishes it on every change to `main` (#2).
- The live race runs Jev against a challenger, with each lane's cost.

## Results (2026-10-07, all 3,250 cases)
| | Jev 1.13 | GPT-6 Luna Decisions |
|---|---|---|
| Accuracy, all decisions | **76.7%** | 74.6% |
| Calibration error | **6.1%** | 9.8% |
| Median latency, 8 in flight | 372 ms | **363 ms** |
| Cost, whole run | **$0.091** | $0.131 |

Jev leads mainly on natural-language inference (XNLI is 15 to 19 points apart in all three languages); Luna wins 5 datasets, mostly Arabic classification. Luna returned a 502 on the same 2 cases on every retry; they count as wrong.

TypeSafe's Jev 1.14 preview on all 3,250 cases, and every API model re-timed from one machine so latency compares fairly (#10).

## Jev 1.14
| Model | Index | English | Arabic | Calibration error | Median latency | Cost per 1,000 calls |
|---|---|---|---|---|---|---|
| **Jev 1.14** | **79.3** | **78.8** | **80.3** | 6.0% | **136 ms** | $0.028 |
| Jev 1.13 | 79.0 | 78.5 | 79.9 | 6.1% | 150 ms | $0.028 |

- 8th of 16 on the System One Index, 0.3 points above Jev 1.13: within run-to-run noise (a same-day re-run of Jev 1.13 moved single datasets by up to 1.5 points).
- One clear gain: customer-service decisions in typed-decisions, 83.6% against 77.4%.
- Same price and the same billed tokens as Jev 1.13. Every call succeeded.

## Latency, re-timed
Every charted API model ran all 3,250 cases again from one cloud server, 8 calls in flight, with models from the same maker at different times. Only latency comes from these runs; accuracy, calibration and cost stay from each model's original run.

- Every model got faster, but unevenly: from the earlier machine the same calls took 1.5 to 3.5 times as long.
- The two Jevs are the fastest API models (136 and 150 ms); Liquid AI d1 (188 ms), Drex v1.5 and Clef Omni now come before GPT-6 Luna Decisions.
- `set_latency.py` copies latency from re-runs into `results.json`. Every latency chart carries a note on what the numbers include.
